About this dashboard

A free, independent reference for how the UK is doing, built only from official public data.

What it shows

Each indicator shows the UK's trend over time and how the UK compares with a group of similar countries. Comparisons use only the latest period for which every country shown has data, and only where the countries measure the same thing in the same way.

What it does not claim

The figures describe outcomes. They do not, on their own, show what caused those outcomes, or how much credit or blame belongs to any government. Where it helps, we mark when governments changed so you can make your own judgement.

Places

The United Kingdom is England, Wales, Scotland and Northern Ireland. Great Britain excludes Northern Ireland. Some official figures cover only Great Britain or only England; each indicator says exactly what it covers.

How current is it?

Each indicator shows the period the latest figures describe and when we last checked the source. If a check is late, the page says so.

Open source

The code, definitions and saved source data are public on GitHub. Corrections and suggestions are welcome there.
